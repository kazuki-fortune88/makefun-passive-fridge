A tiny Python program that writes one passive-aggressive note from a smart fridge to its owner — dry, petty, and specific, exactly the kind of thing a smug fridge would display on its door screen.

## The line

> You opened me 14 times today and ate nothing. The leftovers have started a group chat — and you're the only topic.

## Run

```sh
python3 main.py
```

This writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
